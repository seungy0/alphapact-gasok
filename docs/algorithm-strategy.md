# AlphaPact 알고리즘 전략

[알고리즘 전략 마켓](https://alphapact.pages.dev/copy/algorithms)에서 지갑을 연결하고 **알고리즘 등록**을 선택합니다. 전략 이름과 신호당 최대 거래 금액을 입력한 뒤, 조건을 직접 쓰거나 JSON 파일을 불러옵니다. 지갑 서명이 완료되면 같은 전략을 다른 지갑으로 팔로우할 수 있습니다.

## 이동평균 교차 예시

```json
{
  "buy": { "crossUp": [{ "sma": [0, 2] }, { "sma": [0, 4] }] },
  "sell": { "crossDown": [{ "sma": [0, 2] }, { "sma": [0, 4] }] }
}
```

최근 두 종가의 평균이 최근 네 종가의 평균을 위로 교차하면 매수하고, 아래로 교차하면 매도합니다. 두 조건이 모두 참이거나 모두 거짓이면 대기합니다.

- `{"close":0}`은 최신 종가입니다. 1은 직전 종가이며 최대 7까지 사용할 수 있습니다.
- `{"sma":[0,2]}`는 최신 종가부터 두 개의 평균입니다. 사용 가능한 범위는 최근 8개 종가입니다.
- `{"usd":2000}`은 가격 기준값입니다. 소수 둘째 자리까지 입력할 수 있습니다.
- `gt`와 `lt`는 두 가격을 비교합니다. `crossUp`과 `crossDown`은 직전 캔들과 비교해 교차를 검출합니다.
- `and`와 `or`에는 조건 두 개를, `not`에는 조건 하나를 입력합니다.

## 신호와 교환 확인

서명은 등록할 조건의 해시를 포함합니다. GIWA 계약이 해시와 조건 바이트를 기록하고, 같은 계약이 2분마다 합성 ETH 종가 리플레이의 새 캔들을 기준으로 조건을 계산합니다. 마켓에서 등록된 조건과 해당 캔들의 판단을 볼 수 있습니다.

팔로워는 한 번 서명해 거래당 한도, 최근 24시간 기준 총 거래 한도, 권한 만료 시각을 설정합니다. AlphaPact는 승인 이후에 생성된 매수·매도 신호를 자기 계정의 가스로 전송합니다. GIWA 계약은 신호를 다시 계산한 결과와 비교하고 계정의 권한, 잔액, 거래 한도, 최소 15분 거래 간격을 적용합니다. 주문이 들어갈 때 캔들이 바뀌면 이전 신호는 거부됩니다. 주문이 체결되면 GIWA 영수증을 볼 수 있습니다.

이 버전은 공개된 JSON 조건식을 실행합니다. 교환에는 고정 환율 1 tETH당 2,000 tUSD와 가치가 없는 테스트 토큰을 사용합니다. 전략 평가용 합성 종가는 체결 환율과 별개입니다. 등록하면 조건과 전략 버전이 공개됩니다.
